# Contributing to Andalus Design

Thank you for helping build Andalus.

## Developer Certificate of Origin (DCO)

Every commit must be signed off, certifying that you have the right to submit it under this project's license. Read the full text in [DCO](DCO).

Sign off by adding `-s` to your commit:

```
git commit -s -m "Add button component"
```

This appends a line to the commit message:

```
Signed-off-by: Your Name <your.email@example.com>
```

Commits without a sign-off cannot be merged.

## Design-language contributions

Changes that touch the design language itself — tokens, color, proportion, geometry, motion, typography — must include:

1. **The reasoning** behind the decision.
2. **The cultural or historical source** it draws on, where applicable.

These changes are reviewed against the system's Islamic foundations so that the language is not diluted as the project grows.

## Bidirectional support

Every component must work correctly in both RTL and LTR. Include Arabic examples in your pull request.
